# X9-GPT
## by[ @luizfernandoziron](https://instagram.com/luizfernandoziron)
### Proof of concept (ONLY FOR EDUCATIONAL PURPOSES)

It allows memory extraction from chatgpt (and basically any other LLM). You will need to create a discord webhookurl and you also need a physical device able to run bad-usb through duckscripts (m5, lilygo, flipperzero, rubberducky...)

Tutorial:
Replace YOUR_DISCORD_WEBHOOK_HERE for your actual webhook url. Then just run the duckscript on your device (check your device/firmware documentation)
